## Agent skills

### Issue tracker

Issues vivem como arquivos markdown em `.scratch/<feature>/`. Veja `docs/agents/issue-tracker.md`.

Cinco roles canônicas com nomes padrão (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). Veja `docs/agents/triage-labels.md`.

### Domain docs
